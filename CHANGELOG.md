# Changelog

## Unreleased

- Focused quick start with expected output and a guide to choosing a control.
- Four-case GIF demo rendered from captured CLI output, with an accessible
  transcript and an optional authoring script.
- Executable Python walkthrough covering gradients, tied-value drift, outcome
  representations, identical decisions, and HCA support boundaries.
- Explained CLI parameters, ranges, and defaults in `demo --help`.
- Scientific/reproduction issue forms, a pull request template, and a scoped roadmap.
- CI now executes the walkthrough's Python examples.

## 0.1.0

- Exact, CPU-only two-step credit-assignment diagnostics.
- All 240 fixed theory conditions and a command to recompute them.
- Independent ordered-enumeration and finite-difference checks.
- Explicit inverse-ratio support handling for zero-success actions.
- Same-decision coefficient example and controls against overgeneralization.
- A readable Markdown report recomputed from the complete grid.
- CLI checks for corrupt reference files, invalid inputs, and report reproducibility.
- English and Chinese documentation, source attribution, contribution guidance,
  and a Windows/Ubuntu CI matrix with Python 3.10/3.12.

Publication details and tagged source archives are recorded in
[GitHub Releases](https://github.com/Cookie-27/credit-assignment-sanity-checks/releases).
